# Библиотека КАИТ

## Практика ПП03 Модуль 1

Умаров Джабраил Мунавварович, ИСПО332. Модуль 1, 16 часов, период 03.11–05.11.2026.
Актуальный [отчёт](practice/m01/Отчёт_03.10.2026.docx) содержит 20 страниц, 12 рисунков и 8 таблиц.
Все подтверждения и соответствующие разделам отчёта файлы перечислены в [материалах М01](practice/m01/README.md).

Приложение проверено в отдельном SQLite-окружении. Запуск на личном компьютере студента ещё не подтверждён.
Опубликованного сайта нет: http://127.0.0.1:8080 — адрес локального сервера после запуска.
Основной MySQL/MariaDB-вариант описан ниже, но на проверочном стенде не запускался.
После функционального дополнения CSV в приложении 2048 строк кода — минимум 2000 выполнен. Исходные 1840 строк и история до доработки сохранены отдельно. Выбор проекта и допуск по практике согласуются с руководителем.

Имя отчёта содержит дату 03.10.2026; дата исследования и снимков — 03.11.2026.

Веб-приложение для библиотеки колледжа: электронный каталог, отзывы читателей, бронирование,
выдача и возврат книг, учёт должников.

Для личного Windows подготовлены [пошаговый запуск](practice/m01/windows-start.md) и файл start-library.cmd в корне. [Сверка с методичкой](practice/m01/requirements.md) содержит подтверждения по каждому пункту. Для сдачи также доступна побайтно одинаковая копия [ISPO332_Umarov_M01.docx](practice/m01/ISPO332_Umarov_M01.docx).

## Возможности

- **Читатель:** поиск по каталогу, карточка книги с отзывами, бронирование, личный кабинет с историей.
- **Библиотекарь:** экспорт отфильтрованного каталога в CSV, выдача книг по инвентарному номеру, приём книг со штрафом за просрочку, список должников с выгрузкой в Excel, добавление книг и обложек.
- **Администратор:** управление пользователями и ролями.

## Правила библиотеки

- Студент может взять не более 5 книг на 14 дней, преподаватель — не более 10 книг на 30 дней.
- Если срок возврата выпадает на выходной, он переносится на понедельник.
- Студентам с просроченными книгами новые книги не выдаются.
- Штраф за просрочку — 10 рублей в день (для студентов).

## Технологии

PHP 8, MySQL 8, без фреймворков. Клиентская часть — HTML, CSS и JavaScript (fetch API).

## Установка

Для основного варианта нужны PHP 8 с расширениями PDO, pdo_mysql, mbstring и MySQL 8
или MariaDB 10.6+. Папка `public/` должна быть корнем сайта; остальные папки не должны
быть доступны через веб-сервер. Встроенный сервер PHP подходит для локальной разработки.

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Скопируйте `.env.example` в `.env` (`cp .env.example .env` в Git Bash/Linux или
   `Copy-Item .env.example .env` в PowerShell).
3. Создайте пустую базу `kait_library` с кодировкой utf8mb4. В `.env` задайте
   DB_HOST, DB_PORT, DB_NAME, DB_USER и DB_PASS своего локального сервера.
   `.env` исключён из Git; не добавляйте туда реальные данные учебной организации.
4. Импортируйте `database/schema.sql`, затем **один раз** `database/seed.sql` в эту БД.
   Например, в Git Bash/Linux (пароль вводится по запросу клиента):
   ```bash
   mysql -u root -p -e "CREATE DATABASE kait_library CHARACTER SET utf8mb4;"
   mysql -u root -p kait_library < database/schema.sql
   mysql -u root -p kait_library < database/seed.sql
   ```
   В PowerShell удобнее открыть клиент `mysql -u root -p kait_library` и выполнить
   `source database/schema.sql;`, затем `source database/seed.sql;`.
5. Установите APP_URL=http://127.0.0.1:8080 и выполните из корня:
   ```bash
   php -S 127.0.0.1:8080 -t public
   ```
6. Откройте http://127.0.0.1:8080/. Учебные учётные записи описаны в `database/seed.sql`.
   Тестовые записи и их общий пароль предназначены только для изолированного стенда.

Это уточнённая инструкция основного варианта MySQL; результаты проверки модуля 1
получены на альтернативном SQLite-стенде ниже, а не на MySQL.

### Проверочный стенд модуля 1 с SQLite

В `src/Database.php` уже есть поддержка DB_DRIVER=sqlite. Чтобы проверить приложение
без сервера MySQL, нужен PHP с PDO, pdo_sqlite, mbstring, session, json и filter.

```bash
python practice/m01/init-sqlite.py ../runtime/library.sqlite
```

Скрипт создаёт новую БД из исходных schema.sql и seed.sql, не перезаписывая существующую.
В локальном `.env` укажите DB_DRIVER=sqlite и DB_NAME с **абсолютным путём** к созданному файлу.
Проверенная команда на Linux с загруженным отдельным FrankenPHP 1.13.4 (PHP 8.5.12):

```bash
../runtime/frankenphp php-server --root public --listen 127.0.0.1:8080
```

FrankenPHP скачивается отдельно; исполняемый файл и БД в репозиторий не включены.
SQLite здесь служит только для проверки запуска: типы ENUM, ограничения длины и
правила сравнения строк MySQL воспроизводятся не полностью. Переносимость основного
варианта на MySQL этим тестом не подтверждается. Протокол: `practice/m01/run-log.md`.

## Выгрузка каталога CSV

Войдите библиотекарем или администратором, откройте каталог, задайте поиск, жанр и сортировку, затем нажмите «Скачать каталог CSV». Выгружается весь отобранный список, а не только текущая страница. Файл UTF-8 с BOM содержит 11 столбцов, включая количество экземпляров по состояниям. Гостю и читателю выгрузка недоступна.

Результаты 13 проверок: [csv-checks.json](practice/m01/csv-checks.json). Повторить на установленном PHP можно из корня: `python practice/m01/test-catalog-export.py --php C:\xampp\php\php.exe`. Исторические метрики — [metrics.md](practice/m01/metrics.md), актуальные — [current-metrics.md](practice/m01/current-metrics.md). Доработка и итоговый отчёт представлены в [PR № 3](https://github.com/12112007df/kait-library/pull/3).
