# Ответы на контрольные вопросы модуля 1

1. **Форк и клон.** Форк - отдельный репозиторий на GitHub со связью с исходником.
   Клон - локальная копия репозитория с историей. Исходник - AlexandrAndreevichB/kait-library,
   мой форк - dzabrailumarov2007-hue/kait-library. Изменения практики отправляются в мой форк.
2. **Стек по файлам.** package.json указывает на Node.js/JavaScript, composer.json -
   PHP-пакеты, requirements.txt/pyproject.toml - Python. В моей библиотеке этих файлов нет:
   PHP подтверждается public/index.php, MySQL - database/schema.sql и .env.example,
   клиентский JavaScript - public/assets/js/catalog.js.
3. **Команды Git.** log --graph показывает историю/ветвления; shortlog -sn - число коммитов
   по авторам; blame - автора и коммит каждой строки. Здесь 36 исходных коммитов, три
   автора, есть merge feature/reviews; 193 из 200 строк LoanService принадлежат Ковалёву.
4. **Горячая точка.** Часто изменяемый файл с вероятно важной или нестабильной логикой.
   public/api.php и public/index.php менялись по 10 раз; LoanService.php - 9.
   Ревью этих файлов охватывает основные маршруты и правила выдачи.
5. **Фактор автобуса.** Минимальное число участников, уход которых ставит продолжение
   работы под угрозу. По одному числу коммитов его точно не измерить. Для LoanService
   оценка около 1 из-за концентрации 193/200 строк у одного автора; для всей команды
   такой точности история не даёт.
6. **Файл .env.** Содержит локальные параметры и может содержать пароли; хранится
   локально, образец - .env.example. При утечке действующий секрет сначала отзывают
   или меняют, затем по согласованному плану очищают историю и проверяют другие копии.
   Простое удаление текущего файла не удаляет секрет из старых коммитов.
7. **Признаки отсутствия поддержки.** Смотрят дату и распределение коммитов, релизы,
   ответы в задачах/PR, состояние сборки и зависимостей. В исходной библиотеке последний
   коммит 19.05.2025, до исследования прошло 533 дня, тегов нет. Это сигнал риска,
   но не доказательство окончательного прекращения проекта: локальная проверка запуска прошла.
