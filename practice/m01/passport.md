## 4. Зависимости

В исходнике нет сторонних Composer/npm-пакетов. Поэтому список 10-15 таких пакетов
с выдуманными версиями не составлялся. Ниже реальные зависимости исполнения и
инструменты стенда. Стандартные расширения не являются отдельно подключёнными
библиотеками приложения.

| Компонент | Требование или фактическая версия | Для чего нужен |
|---|---|---|
| PHP | 8 по README; стенд 8.5.12 | Исполнение страниц и API. |
| PDO | Расширение PHP; версия стенда в runtime.json | Соединение и подготовленные SQL-запросы. |
| pdo_mysql | При DB_DRIVER=mysql; на стенде не использовался | Соединение с основной MySQL/MariaDB. |
| mbstring | Используется mb_strlen; версия стенда в runtime.json | Длина строк, включая кириллицу. |
| session | Расширение PHP; версия стенда в runtime.json | Сеанс входа. |
| json | Расширение PHP; версия стенда в runtime.json | JSON для Fetch API. |
| filter | Расширение PHP; версия стенда в runtime.json | filter_var для email. |
| MySQL / MariaDB | MySQL 8 / MariaDB 10.6+ по исходнику | Основное хранилище; здесь не запускалось. |
| Браузер с Fetch API | Chromium 151 на стенде | Формы и асинхронные запросы. |
| FrankenPHP | 1.13.4, только стенд | Локальный HTTP-сервер с PHP. |
| pdo_sqlite / SQLite | Альтернативная ветвь Database.php; версия в runtime.json | Изолированная локальная БД. |
| Python | 3.12.14 на стенде | Скрипты статистики, проверки, подготовки SQLite. |

Версии сторонних пакетов оценить на устаревание нельзя: пакетов и lock-файлов нет.
Возраст кода не доказывает известную уязвимость. Самостоятельные риски исходника:
MD5 паролей в Auth.php, конкатенация параметров SQL в BookRepository.php, неполная
проверка роли при loan.issue в api.php. Находки зафиксированы для следующих модулей.

## 6. Запуск

Приложение запущено локально на PHP 8.5.12 / FrankenPHP 1.13.4 с SQLite,
поддержка которой уже реализована в src/Database.php. Версии и проверки:
[run-log.md](run-log.md), [runtime.json](runtime.json); app-running.png, app-librarian.png.
В исходном README пропущены копирование .env.example, импорт seed.sql,
расширение mbstring и настройка подключения. Основная инструкция MySQL дополнена
в README; отдельный SQLite-вариант документирован как проверочный стенд.

Рабочие команды из корня форка:

```bash
python practice/m01/init-sqlite.py ../runtime/library.sqlite
cp .env.example .env
# Локальный .env: DB_DRIVER=sqlite, DB_NAME=абсолютный путь к library.sqlite,
# APP_URL=http://127.0.0.1:8080. Файл .env не добавляется в Git.
../runtime/frankenphp php-server --root public --listen 127.0.0.1:8080
```

Скрипт переносит schema.sql и seed.sql в изолированную SQLite. Начальные данные:
7 таблиц, 6 пользователей, 6 жанров, 10 книг, 14 экземпляров, 5 выдач,
0 броней, 3 отзыва. Проверка внешних ключей успешна.
SQLite не воспроизводит MySQL ENUM, сравнение строк и ограничения длины;
smoke-тест не равнозначен полноценной проверке на MySQL. Запуск на компьютере
студента и настройка его SSH этим стендом не подтверждаются.

## 7. Вывод о проекте

Я исследовал веб-приложение с 35 файлами кода и 36 исходными коммитами,
выделил две точки входа и семь таблиц базы данных.
Структура проекта понятна, но центральные обработчики часто менялись и требуют ревью.
История показывает работу трёх авторов, при этом 193 из 200 строк сервиса выдачи
принадлежат одному участнику, что создаёт риск потери знаний.
Отсутствие обновлений 533 дня, тегов и автоматических тестов ограничивает оценку
зрелости, хотя локальный запуск с альтернативной SQLite выполнен.
Я дополнил README и зафиксировал расхождения штрафов, MD5 и построение SQL
как направления следующего ревью.
До допуска нужно согласовать объём 1840 строк кода против минимума 2000 и выбор
проекта с руководителем; паспорт не подтверждает такое согласование.
