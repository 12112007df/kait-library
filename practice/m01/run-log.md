# Протокол локального запуска исходного среза

Дата: 03.11.2026. Исходник: fa96e45cc8d3eac09a6b40496ef120d688406ea5.
Стенд: FrankenPHP 1.13.4, PHP 8.5.12, SQLite 3.45.2, Chromium 153.0.8010.0.

Этот протокол относится к изолированному проверочному окружению. Запуск на личном компьютере студента ещё не подтверждён. Публичного сайта нет: http://127.0.0.1:8080 доступен только там, где запущен локальный сервер.

## Подготовка

В отдельную временную папку скачан FrankenPHP из официального релиза php/frankenphp v1.13.4.
Python 3.12.14 создал SQLite скриптом init-sqlite.py из исходных schema.sql и seed.sql.
В локальном .env установлен DB_DRIVER=sqlite и абсолютный DB_NAME.
Команда сервера: `../runtime/frankenphp php-server --root public --listen 127.0.0.1:8080`.
Проверки выполнены браузером Playwright с Chromium; снимки получены с работающих страниц.
Проверка синтаксиса: token_get_all(..., TOKEN_PARSE) для всех 26 исходных PHP-файлов.

## Границы проверки

10 проверок пройдены на SQLite. MySQL/MariaDB в этом окружении не запускались.
Первоначальная попытка установить PHP/MySQL через системный пакетный менеджер не завершилась;
использован отдельный FrankenPHP без изменения исходных PHP-файлов приложения.
SQLite не воспроизводит MySQL ENUM, ограничения VARCHAR и правила сравнения строк.
Автоматизированный smoke-тест не является полным тестированием безопасности или бизнес-правил.
SSH на личном компьютере, инструктаж и согласование проекта не проверялись.
