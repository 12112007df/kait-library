# Запуск библиотеки на Windows

Это запуск на личном компьютере для выполнения шага 5 модуля 1.
Подготовленный запуск использует SQLite — тот же альтернативный драйвер, на котором проверено приложение в отчёте.
Основной вариант MySQL/MariaDB описан в корневом README.

1. Установите Python 3.8+ и PHP 8 с расширениями PDO, pdo_sqlite, mbstring, session, json и filter. Python нужен и для скриптов самой практики. Если установлен XAMPP в C:\xampp, помощник найдёт его PHP автоматически.
2. Скачайте свой форк: на GitHub откройте Code → Download ZIP и полностью распакуйте архив. Для работы с историей Git вместо ZIP используйте `git clone https://github.com/12112007df/kait-library.git`.
3. В распакованной папке дважды нажмите `start-library.cmd`. Оставьте открывшееся окно работающим. После успешного запуска браузер откроет http://127.0.0.1:8080/.
4. Убедитесь, что каталог показывает книги, выполните поиск «Чистый» и сохраните собственный скриншот запущенного приложения. Для выполнения требования методички снимок должен быть получен на вашем компьютере.
5. Для остановки сервера нажмите Ctrl+C в окне запуска. Повторный запуск использует существующие данные и не импортирует тестовые записи заново.

При первом запуске создаются локальный `.env` в корне и тестовая БД в `%USERPROFILE%\.kait-library\library.sqlite`. Они не включаются в коммит. Существующий `.env` с другой СУБД не перезаписывается: используйте отдельную рабочую копию для SQLite.

## Если запуск остановился

| Сообщение | Действие |
|---|---|
| Python не найден | Проверьте `py -3 --version` или `python --version`; при установке Python включите Add Python to PATH. |
| PHP не найден | Установите PHP или XAMPP; либо укажите путь командой ниже. |
| Нет pdo_sqlite или mbstring | В используемом php.ini включите `extension=pdo_sqlite` и `extension=mbstring`; проверьте путь extension_dir. |
| Порт занят | Закройте прежнее окно сервера или запустите помощник с `--port 8081`. |
| Не удалось запустить PHP | Проверьте `C:\xampp\php\php.exe -v`; для официальной Windows-сборки PHP нужен Microsoft Visual C++ Runtime соответствующей разрядности. |

Пример из PowerShell в корне проекта:

```powershell
py -3 practice/m01/start-library.py --php C:\xampp\php\php.exe --port 8081
```

Для проверки входа используйте только учебные данные из database/seed.sql: `librarian@kait20.ru`, пароль `password`. Отдельное требование входить под всеми ролями в М01 отсутствует; достаточно подтвердить запуск. Учебный сервер слушает только 127.0.0.1.

Официальные источники установки: https://www.python.org/downloads/windows/ ; https://www.php.net/manual/en/install.windows.manual.php ; https://www.apachefriends.org/download.html .
Добавление помощника в репозиторий не подтверждает, что запуск на компьютере студента уже выполнен.
