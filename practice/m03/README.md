# Модуль 3. Изменение характеристик кода

Умаров Джабраил Мунавварович, ИСПО332.

Выполнены сравнение VS Code и Apache NetBeans, измерения до и после, рефакторинг и контроль поведения.

- `metrics.md`: сравнение двух IDE, замеры до/после, история семи изменений кода и находки без исправления.
- `metrics-raw.md`: два исходных замера штатным скриптом преподавателя.
- `formatting-diff.patch`, `formatting-stat.txt`: эксперимент с форматированием; изменения отменены.
- `control-summary.json`, `control-run.py`, `control-run.txt`: совпадение 14 сценариев.
- `syntax-check.php`, `syntax-check.txt`: проверка синтаксиса 27 PHP-файлов и равенства токенов двух вариантов форматирования.
- `run-log.md`: условия и порядок воспроизведения.

Сложность `LoanService::issue` снижена с 21 до 7, длина — с 97 до 40 NLOC (47 физических строк). Результаты четырёх сценариев через интерфейс и 14 HTTP-сценариев сохранены.

Отчёт Microsoft Word с 9 таблицами и 11 подписанными рисунками передаётся отдельно. Все снимки инспекций, различий форматирования и контрольных сценариев включены в отчёт.
