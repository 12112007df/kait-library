## 2. Где меняется каждая характеристика

Фактически проверенная среда — Linux. В Windows некоторые сочетания клавиш отличаются.

| Характеристика | VS Code | Apache NetBeans 31 |
|---|---|---|
| Кодировка файла | UTF-8 в строке состояния → Save/Reopen with Encoding | При создании проекта Default Encoding; Properties → Sources → Encoding, UTF-8 |
| Окончания строк | LF/CRLF в строке состояния; Change End of Line Sequence → LF | Unix (LF) в строке состояния → Unix / Mac OS 9 / Windows |
| Табуляция → пробелы | Convert Indentation to Spaces, четыре пробела | Tools → Options → Editor → Formatting, PHP, Tabs And Indents, Expand Tabs to Spaces; затем Format |
| Форматирование файла | Format Document; в проверенном Linux Ctrl+Shift+I, в Windows Shift+Alt+F | Source → Format, Alt+Shift+F |
| Переименование | F2 / Rename Symbol; у Intelephense это платная функция, лицензия не приобреталась | Ctrl+R, локальное переименование с обновлением всех употреблений; выполнены три переименования |
| Выделение метода | Готовая PHP-команда в установленном бесплатном наборе не использовалась; выделение выполнено вручную в редакторе | В меню Refactor для PHP нет Extract Method; доступны Rename, Move, Copy, Safely Delete |
| Инспекция | Problems, Ctrl+Shift+M; диагностика Intelephense | Window → Action Items, Ctrl+6; текущий проект и отдельные подсказки в редакторе |
| Хранение настроек | Пользовательский User/settings.json; проектные .vscode/settings.json, правила EditorConfig в .editorconfig | Пользовательский каталог config/Preferences; настройки проекта nbproject. В М03 метаданные вынесены в отдельный каталог и не коммитятся |

Платность Rename подтверждена README установленного официального расширения Intelephense. Наличие общей команды F2 в VS Code само по себе не означает доступности PHP-переименования. Настройки для команды и линтер будут согласованы в М04.

## 4. Конфликт форматирования

Файл: `src/helpers.php`. VS Code Format Document оставил файл без изменений; контрольный коммит `47ec648` зафиксировал эту точку. После Alt+Shift+F в NetBeans:

```
 src/helpers.php | 44 ++++++++++++++++++--------------------------
 1 file changed, 18 insertions(+), 26 deletions(-)
```

NetBeans помещает открывающую скобку функции на строку объявления и добавляет пробел после приведения типа: `(string)$value` → `(string) $value`. VS Code сохраняет открывающую скобку на следующей строке и исходное написание приведения. Полный diff — `formatting-diff.patch`, снимок включён в отдельный отчёт Microsoft Word. Обе версии имеют одинаковые PHP-токены за исключением пробелов, что проверено `syntax-check.php`.

Затем выполнен `git restore src/helpers.php`. Экспериментальная версия не включена в итоговый код. Для команды такие различия создают лишние изменения, затрудняют просмотр полезной правки и повышают вероятность конфликтов. Единые правила форматирования будут согласованы в М04.
