## Порядок проверки

1. Установить Python и lizard, PHP с PDO SQLite либо использовать FrankenPHP. Клонировать проект.
2. Командой `python practice/m01/init-sqlite.py /absolute/path/base.sqlite` создать отдельную базу; существующая база не перезаписывается.
3. Создать копию base.sqlite с именем library.sqlite и локальную `.env`, указав `DB_DRIVER=sqlite`, абсолютный `DB_NAME`, соответствующий `APP_URL`.
4. Запустить PHP-сервер, например `frankenphp php-server --listen 127.0.0.1:8013 --root public`.
5. Для исходного среза и изменённого кода выполнить `python practice/m03/control-run.py --base /absolute/path/base.sqlite --database /absolute/path/library.sqlite --url http://127.0.0.1:8013 --label before` и соответственно `--label after`. Скрипт заменяет только явно указанную одноразовую тестовую базу; рабочую базу использовать нельзя. При after сравниваются сохранённые исходные ответы и состояния таблиц. Полные JSON-файлы создаются только локально; для публикации предназначен `control-summary.json`.
6. Проверить синтаксис: `frankenphp php-cli practice/m03/syntax-check.php`. Для обычного PHP подходит запуск `php practice/m03/syntax-check.php`.
7. Измерить код штатным скриптом преподавателя `tools/metrics.py`, указав папку проекта, label и путь metrics-raw.md. Этот файл уже содержит ровно два замера с lizard.
8. Для проверки сдачи использовать `python /path/to/PP03/tools/check_practice.py . --module 3`.

Снимки окончаний строк eol-before.txt и eol-after.txt содержат только файлы приложения: config, database, public, src, templates и файл запуска. Материалы других модулей в эти списки не включены.
