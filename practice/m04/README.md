## 4. Сравнение способов передачи настроек

| Способ | Что передаёт | Плюсы | Минусы | Когда использовать |
|---|---|---|---|---|
| Файлы в репозитории | Правила Git, редактора, линтера и проекта IDE | Версионируются, доступны после clone, проверяются при ревью | Не устанавливают программы и расширения автоматически | Основной способ для команды |
| Экспорт профиля или настроек | Выбранные настройки и список расширений конкретной IDE | Быстрая настройка одинаковой среды | Зависит от IDE и версии; нужно исключать личные данные | При подключении нового участника или переносе рабочего места |
| Settings Sync через аккаунт | Личные настройки, сочетания клавиш и расширения VS Code | Удобно между своими компьютерами | Требует аккаунта; не является общим набором правил проекта | Для личного удобства поверх командных правил |

Для команды основными являются файлы в Git и независимая проверка PHPCS. Экспорт IDE дополняет их. Синхронизация аккаунта не использовалась и не требуется для чистой проверки.

Диаграммы не требуются заданием М04.
