## Браузеры и условия

| Кандидат | Движки рендеринга и JavaScript | Версия для сравнения |
|---|---|---|
| Google Chrome | Blink, V8 | Определить на стенде |
| Mozilla Firefox | Gecko, SpiderMonkey | 153.0 (сборка Playwright) |
| Microsoft Edge | Blink, V8 | Определить на стенде |

Сравнение проводить на одном компьютере с чистыми профилями, без расширений, с одинаковым масштабом и питанием. Записать ОС, характеристики компьютера и версии браузеров и тестов. Выполнить Speedometer, JetStream и MotionMark. Память измерить по сумме процессов через минуту после открытия пяти одинаковых вкладок. Для холодного запуска завершать все процессы браузера перед каждым из трёх повторов. В Firefox 153.0 время от запуска процесса до подключения Playwright составило 774, 286 и 301 мс. Среднее — 454 мс. Каждый повтор запускал новый процесс, файловый кэш не очищался. Бенчмарки и замер памяти ещё нужны.

## Сеть

В [HAR модуля 2](../m02/scenario1.har) сохранён исторический прогон Chromium 157.0.8103.38.

| Запрос | HTTP | Ожидание в HAR, мс |
|---|---:|---:|
| POST регистрации | 302 | 6,617 |
| GET каталога после регистрации | 200 | 1,406 |
| GET books.search, загрузка каталога | 200 | 8,016 |
| GET books.search, поиск «Чистый» | 200 | 1,484 |

Время взято из `timings.wait`. У двух поисковых запросов разные параметры, поэтому они не образуют серию повторов. Для базовой линии М10 провести три обновления для каждого из трёх запросов: каталог, поиск с фиксированными параметрами и страница должников. Для каталога также записать количество запросов и переданный объём с одинаковыми настройками кэша.

### Замеры на текущем стенде

FrankenPHP 1.13.4, PHP 8.5.12, демонстрационная SQLite, localhost. В Firefox использованы Navigation Timing для страниц и время от отправки запроса до начала ответа для поиска. Все запросы вернули HTTP 200. Поиск вернул одну книгу.

| Маршрут | Firefox, три замера, мс | Среднее, мс | curl, три контрольных замера, мс |
|---|---|---:|---|
| Каталог | 5; 2; 1 | 2,67 | 1,796; 1,280; 0,849 |
| Поиск «Чистый» | 1,205; 1,567; 1,215 | 1,329 | 1,813; 0,850; 0,854 |
| Должники | 1; 1; 1 | 1,00 | 2,436; 1,444; 1,019 |

Браузерные значения и curl измерены разными средствами. Контрольные значения curl включают установку локального соединения.

## DevTools и Lighthouse

В каждом браузере проверить эмуляцию 375 px, замедление сети, точки останова JS, отображение HttpOnly/Secure/SameSite и экспорт HAR. Для сравнения использовать только демонстрационный стенд, сохранять HAR без паролей и значений cookies. По каталогу выполнить Lighthouse Desktop и Mobile. Сохранить HTML и скриншоты с показателями Performance, Accessibility, Best Practices и SEO.
