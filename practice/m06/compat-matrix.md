## Браузеры и условия

| Кандидат | Движки рендеринга и JavaScript | Версия для сравнения |
|---|---|---|
| Google Chrome | Blink, V8 | Определить на стенде |
| Mozilla Firefox | Gecko, SpiderMonkey | 153.0 (сборка Playwright) |
| Microsoft Edge | Blink, V8 | Определить на стенде |

Сравнение проводить на одном компьютере с чистыми профилями, без расширений, с одинаковым масштабом и питанием. Записать ОС, характеристики компьютера и версии браузеров и тестов. Выполнить Speedometer, JetStream и MotionMark. Память измерить по сумме процессов через минуту после открытия пяти одинаковых вкладок. Для холодного запуска завершать все процессы браузера перед каждым из трёх повторов. В Firefox 153.0 время от запуска процесса до подключения Playwright составило 774, 286 и 301 мс. Среднее — 454 мс. Каждый повтор запускал новый процесс, файловый кэш не очищался. Бенчмарки и замер памяти ещё нужны.

Время взято из `timings.wait`. У двух поисковых запросов разные параметры, поэтому они не образуют серию повторов. Для базовой линии М10 провести три обновления для каждого из трёх запросов: каталог, поиск с фиксированными параметрами и страница должников. Для каталога также записать количество запросов и переданный объём с одинаковыми настройками кэша.

### Фильтр, пагинация и отзывы

В отдельной копии демонстрационной SQLite добавлены 30 учебных книг. В обоих браузерах каталог показал 40 книг на 7 страницах. При нажатии «2» API вернул вторую страницу с другим набором книг. Выбор жанра с ID 2 вернул 2 книги и сбросил пагинацию на страницу 1. В карточке книги № 1 запрос списка отзывов вернул HTTP 200, два демонстрационных отзыва появились в интерфейсе. Проверки прошли в Firefox 153.0 и Chromium 153.0.8010.0.

## Память при пяти вкладках

Каждый браузер запущен отдельно. В новом профиле открыты пять одинаковых вкладок каталога. Через 60 секунд подсчитана сумма VmRSS основного процесса и его потомков.

| Сборка | Процессы | Сумма RSS, МиБ |
|---|---:|---:|
| Firefox 153.0 | 11 | 1260,81 |
| Chromium 153.0.8010.0 headless shell | 3 | 263,78 |

Chromium запускался с параметром `--single-process`. Различаются модели процессов и режимы запуска, поэтому эти значения не использованы для выставления сравнительных баллов. Данные внесены на лист «Память» в Excel.

### Гостевая загрузка каталога и cookie

| Проверка | Firefox | Chromium |
|---|---:|---:|
| Количество запросов с чистым профилем | 5 | 5 |
| Объём передач по HAR, байт | 9 049 | 9 049 |
| Ширина окна при адаптивном тесте | 375 px | 375 px |

Запросы включают HTML каталога, CSS, два JS-файла и API поиска. Оба браузера записали HAR через Playwright. Исходные HAR содержали идентификатор гостевого сеанса и удалены после извлечения агрегированных результатов.

Ответ localhost устанавливал `PHPSESSID` с `Path=/`. Атрибуты `HttpOnly`, `Secure` и `SameSite` в HTTP-заголовке отсутствовали. Playwright показал `SameSite=None` для Firefox и `Lax` для Chromium. Эти поля отражают представление браузера. Проверка по заголовку подтверждает отсутствие явно указанного `SameSite`.
