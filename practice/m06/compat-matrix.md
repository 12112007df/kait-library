Сравнение проводить на одном компьютере с чистыми профилями, без расширений, с одинаковым масштабом и питанием. Записать ОС, характеристики компьютера и версии браузеров и тестов. Выполнить Speedometer, JetStream и MotionMark. Память измерить по сумме процессов через минуту после открытия пяти одинаковых вкладок. Для холодного запуска завершать все процессы браузера перед каждым из трёх повторов. В Firefox 153.0 время от запуска процесса до подключения Playwright составило 774, 286 и 301 мс. Среднее — 454 мс. Каждый повтор запускал новый процесс, файловый кэш не очищался. Результаты бенчмарков и отдельного замера памяти приведены ниже.

## Память при пяти вкладках

Каждый браузер запущен отдельно. В новом профиле открыты пять одинаковых вкладок каталога. Через 60 секунд подсчитана сумма VmRSS основного процесса и его потомков.

| Сборка | Процессы | Сумма RSS, МиБ |
|---|---:|---:|
| Firefox 153.0 | 11 | 1260,81 |
| Chromium 153.0.8010.0 headless shell | 3 | 263,78 |

Chromium запускался с параметром `--single-process`. Различаются модели процессов и режимы запуска, поэтому эти значения не использованы для выставления сравнительных баллов. Данные внесены на лист «Память» в Excel.

### Гостевая загрузка каталога и cookie

| Проверка | Firefox | Chromium |
|---|---:|---:|
| Количество запросов с чистым профилем | 5 | 5 |
| Объём передач по HAR, байт | 9 049 | 9 049 |
| Ширина окна при адаптивном тесте | 375 px | 375 px |

Запросы включают HTML каталога, CSS, два JS-файла и API поиска. Оба браузера записали HAR через Playwright. Исходные HAR содержали идентификатор гостевого сеанса и удалены после извлечения агрегированных результатов.

Ответ localhost устанавливал `PHPSESSID` с `Path=/`. Атрибуты `HttpOnly`, `Secure` и `SameSite` в HTTP-заголовке отсутствовали. Playwright показал `SameSite=None` для Firefox и `Lax` для Chromium. Эти поля отражают представление браузера. Проверка по заголовку подтверждает отсутствие явно указанного `SameSite`.

## Расчёт и сдача

Предварительные веса: совместимость — 0,35, DevTools — 0,25, бенчмарки — 0,20, память и запуск — 0,15, сбор сетевой базовой линии — 0,05. Сумма — 1,00. Совместимости присвоен наибольший вес, поскольку целевые браузеры выбираются для рабочего приложения. Итоговый балл — сумма произведений оценок по шкале 1–5 на веса. Предварительно для отладки выбран браузер семейства Chromium, где доступен Lighthouse. Для проверки совместимости проекта нужны Blink и Gecko. Отдельную поддержку Edge следует подтвердить на третьем браузере.

В [книге Excel](weighted-score.xlsx) есть формулы и замеры Firefox и Chromium. Общий балл появится после ввода всех оценок. Замеры Windows и снимки добавлены в [отчёт Word](ISPO332_Umarov_M06.docx). Для итоговой оценки трёх браузеров нужны прогон Edge, версии браузеров Windows, замеры памяти и запуска в одинаковых условиях и проверка производительности Lighthouse. Проверка `check_practice.py --module 6` пройдена на полной истории ветки. Она проверяет состав файлов и коммиты. Для завершения сдачи требуются итоговые измерения, отчёт и слияние PR.
